# 🏝️ Tourism Static Website

A static tourism website showcasing famous tourist destinations using a clean and responsive design.  
This project is built using **HTML, CSS, and Bootstrap** as a beginner-friendly web development project.

---

## 📌 Project Overview

This website highlights tourist destinations through:
- A Bootstrap image carousel
- A detailed view layout styled with CSS
- Attractive typography using Google Fonts
- Simple and clean UI design

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Bootstrap 4  
- Google Fonts  

---

## ✨ Features

- Responsive image carousel
- Full-screen background image
- Card-based content layout
- Clean typography
- Beginner-friendly static website
